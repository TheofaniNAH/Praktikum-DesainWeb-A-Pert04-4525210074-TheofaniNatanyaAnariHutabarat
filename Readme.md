# Deskripsi Proyek #
Proyek ini adalah pembuatan Landing Page Arunika Studio menggunakan HTML dan CSS. Website dirancang sebagai halaman promosi sederhana yang responsif dan dapat diakses dengan baik pada perangkat desktop maupun mobile. Halaman terdiri dari beberapa bagian utama yaitu Header, Hero Section, Layanan, Kontak, dan Footer.

Dalam pengerjaannya menggunakan CSS eksternal, box model, reusable class, serta media query agar tampilan dapat menyesuaikan ukuran layar yang berbeda.

# Penerapan CSS #
Box Model. CSS Box Model diterapkan melalui penggunaan:
1. Margin
2. Padding
3. Border
4. Border Radius
5. Width
6. Height
7. Box Sizing

# Reusable Class #
1. .container
2. .section

# Responsive Design #

Media Query digunakan untuk menyesuaikan tampilan pada layar berukuran di bawah 768px.
Fitur responsive yang diterapkan:

1. Menu navigasi ditampilkan secara vertikal.
2. Card layanan berubah dari 3 kolom menjadi 1 kolom.
3. Ukuran heading disesuaikan agar tetap nyaman dibaca.
4. Layout menjadi lebih fleksibel pada perangkat mobile.

# Fitur Website #
1. Header dengan menu navigasi.
2. Hero section sebagai bagian utama landing page.
3. Tiga layanan utama:
4. Web Design

## Kesimpulan ##
Landing Page Arunika Studio berhasil dibuat menggunakan HTML dan CSS dengan tujuan menampilkan informasi layanan secara sederhana, menarik, dan responsif. Struktur halaman yang terdiri dari Header, Hero Section, Layanan, Kontak, dan Footer membuat informasi tersusun dengan rapi dan mudah dipahami oleh pengguna. CSS digunakan untuk mengatur tampilan visual, warna, tata letak, serta memberikan efek responsive melalui media query. Penerapan reusable class membantu mengurangi penulisan kode yang berulang, sedangkan penggunaan box model mempermudah pengaturan jarak dan tata letak elemen pada halaman. Selain itu, fitur navigasi internal memudahkan pengguna untuk berpindah ke setiap bagian website dengan cepat. Pengujian pada desktop dan mobile menunjukkan bahwa tampilan website tetap nyaman digunakan pada berbagai ukuran layar. Melalui proyek ini, pemahaman mengenai struktur HTML, styling CSS, responsive web design, dan pengelolaan layout website menjadi semakin baik.
